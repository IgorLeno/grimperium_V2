# Skill: Grimperium Docs Maintenance

Use this skill when the task is updating README, docs, changelog, or validating
the Sphinx docs tree.

## Scope

- Update prose docs to match the current repository state.
- Keep `CHANGELOG.md` current under `[Unreleased]`.
- Validate the docs build if the required dependencies are available.

## Ground Rules

- Do not promise autogenerated changelog, README, or technical-report output.
  Update docs intentionally and explicitly.
- Keep `/CLAUDE.md` as the main local behavior contract.
- Archive or redirect stale workflow docs instead of leaving them as competing
  authorities.

## Useful Commands

Changelog and doc maintenance are usually manual edits. When Sphinx validation is
needed and the docs extras are installed, the current docs tree supports:

```bash
poetry run sphinx-build -b html docs/source docs/build/html
```

If docs dependencies are not installed, say so instead of inventing a build
result.
